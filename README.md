# Kamen Rider: Chrono Henshin (fan game)

Game 2D pixel đi qua 27 thế giới Kamen Rider. Fan game phi thương mại.

- **Android:** tải file APK ở [Releases](https://github.com/vpn2k1/kamenrider/releases/latest) (cho phép cài ứng dụng từ nguồn ngoài)
- **Web:** https://vpn2k1.github.io/kamenrider/ (bản web có nút **?** mở bảng hướng dẫn nút bấm ngay trong game)

**Bản 0.2:** mỗi form có 2 skill riêng (U / Y) · Decade Kamen Ride và Zi-O Armor nhiều form · form đặc biệt tụt nộ,
hết nộ về form gốc · hiệu ứng đánh vẽ lại bằng PixelLab · nền riêng cho từng màn · cài đặt âm thanh.

## Bàn phím

| Phím | Tác dụng |
|---|---|
| **A / D** hoặc **← / →** | Di chuyển |
| **Space** | Nhảy · đứng trên bệ: **S + Space** (hoặc bấm đúp **S**) để xuống |
| **S / ↓** (giữ) | Cúi / thủ thế: đạn cao bay qua đầu, đòn cận chiến chỉ còn 40% |
| **W / ↑** (giữ) | Ngắm lên khi có súng (W + A/D bắn chéo) |
| **J** | **Đánh**: bấm liên tục ra chuỗi đấm, đủ đòn thì tự ra cú đá |
| **K** | **Chém** (form có kiếm). Vung đúng lúc đạn bay tới thì **chém tan**; sớm hơn một nhịp, đạn ở mũi lưỡi thì **phản đạn** |
| **H** (giữ) | **Bắn** (form có súng) |
| **L** | **Kỹ năng**: từ form gốc vào form đặc biệt (tốn 10 nộ; mỗi lần bấm vào form kế tiếp). Ở form đặc biệt nộ tụt dần (đánh, bị đánh, hạ quái vẫn cộng nhưng ít hơn lượng tụt), hết nộ thì về form gốc; nút ẩn tới lúc đó. Rider W: L đổi nửa trái, giữ W / ↑ + L đổi nửa phải |
| **U** | **Skill 1** của form (skill nhẹ, 15–20 nộ, hồi 2 giây) |
| **Y** | **Skill 2** của form (skill mạnh, 30–35 nộ, hồi 5 giây) |
| **Shift** | **Né** đòn cận chiến (không tránh được đạn) |
| **I** | **Biến thân** (nộ đầy, đã có Driver) |
| **O** | **Final Attack** (60 nộ) |
| **Esc / P** | Menu: về màn chọn màn |

## Nút cảm ứng (điện thoại, hoặc bấm chuột)

| Nút | Tác dụng |
|---|---|
| **◀ ▶** | Di chuyển |
| **▲** | Nhảy · giữ để ngắm lên |
| **▼** | Cúi / thủ thế · bấm đúp trên bệ để xuống |
| **Đánh** (nút to, góc phải) | Chuỗi đấm rồi tự ra cú đá |
| **Né** (nút to bên phải pad di chuyển) | Né đòn cận chiến |
| **Chém** (vòng ngoài quanh nút Đánh, như Bắn, Kỹ năng) | Form có kiếm · đúng lúc thì chém tan / phản đạn |
| **Bắn** | Giữ để bắn (form có súng) |
| **Kỹ năng** | Vào form đặc biệt (tốn 10 nộ, ẩn khi đang ở form đặc biệt) |
| **Skill 1 · Skill 2 · Final** (vòng trong quanh nút Đánh, hình là icon skill) | Skill của form, Final Attack (60 nộ); số ở góc nút là nộ cần |
| **Biến thân** (cùng chỗ nút Final, dạng người) | Nộ đầy: biến thân |
| **≡** (góc trên trái) | Menu: về màn chọn màn |
| **?** (dưới nút ≡, chỉ bản web) | Mở bảng hướng dẫn nút bấm |

Nút Bắn, Chém, Kỹ năng chỉ hiện khi form hiện tại dùng được. Vòng tối trên nút là thời gian hồi chiêu. Mỗi form có
2 skill riêng theo nguyên tác (xem [docs/SKILLS.md](docs/SKILLS.md)).

## Menu và hội thoại

| Thao tác | Bàn phím | Cảm ứng |
|---|---|---|
| Chọn | **← → ↑ ↓** / **A D W S** | Chạm vào lựa chọn · kéo để cuộn danh sách |
| Xác nhận | **Enter** / **J** | Nút **CHỌN / TIẾP / VÀO MÀN** |
| Quay lại | **Esc** | Nút **◀** |
| Qua câu thoại | **J** / **Enter** / **Space** | Chạm màn hình |
| Bỏ qua cả đoạn thoại | **Esc** | Nút **BỎ QUA** |
| Cài đặt âm thanh (âm lượng, bật / tắt nhạc nền, tiếng đánh, kỹ năng, biến thân, quái, di chuyển, menu) | **▲ ▼** chọn · **◀ ▶** chỉnh / bật tắt | Nút **⚙ Cài đặt** ở màn hình chính, chạm từng dòng để bật / tắt |

## Chế độ COMBAT (2–4 người cùng WiFi)

Dùng đúng các nút như trên. Bấm **Menu** hai lần để bỏ trận.
